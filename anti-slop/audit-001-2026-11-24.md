## Numbered Findings List

### [HIGH Priority — Hard Gate]

1. **R-37** — Missing `DESIGN.md` Style Direction
   - **Location:** `DESIGN.md` (Project root)
   - **Snippet:** File does not exist
   - **Reason:** Project lacks a `DESIGN.md` document defining visual identity, mood, color palette, typography, and explicit dials (ENERGY / RHYTHM / MOTION).

2. **R-39** — Missing Base CSS `cursor: pointer` & Disabled State Affordance
   - **Location:** `src/app/globals.css:120`
   - **Snippet:** `@layer base { * { box-sizing: border-box; ... } body { ... } }`
   - **Reason:** Interactive elements (`button`, `a[href]`, `select`, `summary`, checkboxes, radios) lack `cursor: pointer` and disabled elements lack `cursor: not-allowed` in the base CSS layer.

3. **R-39** — Missing Global `prefers-reduced-motion` Reset in Base CSS
   - **Location:** `src/app/globals.css:1`
   - **Snippet:** `@import "tailwindcss"; ...`
   - **Reason:** Missing global accessibility reset to disable non-essential animations and transitions when the user requests reduced motion.

4. **R-39** — Missing Accessible Name on Theme Toggle Button
   - **Location:** `src/app/page.tsx:1616`
   - **Snippet:** `<button className="theme-btn" onClick={() => setTheme(...)}>`
   - **Reason:** Icon-only theme button contains only raw SVG without `aria-label="Ganti Tema"` or visually hidden text.

5. **R-39** — Missing `aria-label` on Icon-Only Action Buttons in Admin & Dashboard Tables
   - **Location:** `src/components/administrator/` & `src/components/dashboard/`
   - **Snippet:** `<button onClick={handleDelete}><Trash2 size={14} /></button>` (and similar icon buttons)
   - **Reason:** Icon-only action buttons (delete, edit, expand, refresh) lack accessible names for screen readers and keyboard users.

6. **R-32** — Keyboard Focus Ring Suppressed with `outline: none`
   - **Location:** `src/components/questionnaire/QuestionnaireTokenGate.tsx:331, 370`
   - **Snippet:** `style={{ outline: 'none', border: '1px solid var(--border)', ... }}`
   - **Reason:** `outline: none` is applied to form inputs without providing a visible focus indicator (`focus-visible` ring).

7. **R-03** — Mobile Tap Targets Smaller than 44px
   - **Location:** `src/app/globals.css:461`, `src/components/header/NotificationBell.tsx:422, 432`, `src/components/ui/button.tsx:26, 28`
   - **Snippet:** `.theme-btn { width: 32px; height: 32px; }`, action buttons with `height: 28px`
   - **Reason:** Interactive buttons fail the minimum mobile touch target size of 44px without appropriate padding or container sizing.

8. **R-25** — Low Color Contrast on Dimmed Text in Light Mode
   - **Location:** `src/app/globals.css:76`
   - **Snippet:** `--fg-dim: #999999;` against `--background: #ECECEC;`
   - **Reason:** Contrast ratio of `#999999` on `#ECECEC` is 2.4:1, failing the WCAG AA minimum standard of 4.5:1 for normal text.

9. **R-40** — Image Tags Missing Explicit Width and Height Dimensions
   - **Location:** `src/app/page.tsx:584, 1531`, `src/components/dashboard/DashboardView.tsx:676`, `src/components/ui/page-loading.tsx:22`
   - **Snippet:** `<img src="/BM.png" alt="" className="bm-loading-logo" />`
   - **Reason:** Image elements lack explicit `width` and `height` attributes (or aspect-ratio styles), causing Cumulative Layout Shift (CLS).

10. **R-02** — Em Dash (`—`) in Questionnaire Page Titles and Subtitles
    - **Location:** `src/app/kuesioner/page.tsx:14, 22, 39`, `gangguan-tidur/page.tsx:16`, `kesehatan-mental/page.tsx:16`, `psikologi-lingkungan/page.tsx:8`
    - **Snippet:** `title: 'Kuesioner Mandiri — BG-Health'`, `subtitle: 'Epworth Sleepiness Scale — 8 pertanyaan'`
    - **Reason:** Em dash (`—`) is strictly forbidden in UI text by R-02; replace with colon, parentheses, or comma.

11. **R-02** — Em Dash (`—`) in Token Gate and Consent Dialog Copy
    - **Location:** `src/components/questionnaire/QuestionnaireTokenGate.tsx:230`, `src/components/questionnaire/ConsentGate.tsx:35`
    - **Snippet:** `Verifikasi Responden — One-Time Token`, `...kepada QSHE Medic — ketentuan ini berlaku...`
    - **Reason:** Em dash (`—`) used in window title bar and consent disclaimer copy; replace with colon or parentheses.

12. **R-02** — Em Dash (`—`) in App Shell Navigation Labels & Auth Header
    - **Location:** `src/app/page.tsx:82, 120, 1100`
    - **Snippet:** `ariaLabel="Layanan Kuratif — Input"`, `ariaLabel="Higiene Industri — Input"`, `{mode === 'login' ? 'Masuk Akun — BG-Health' : ...}`
    - **Reason:** Em dash (`—`) used in aria labels and auth screen headers; replace with colon or hyphen.

13. **R-02** — Em Dash (`—`) Used as Fallback Placeholder in Data Tables
    - **Location:** `src/components/administrator/AdminProKawan.tsx:60`, `MonitoringKaryawanSakit.tsx`, `PicaRegister.tsx`, `GiziKerjaTable.tsx`, `ErgoSurveyTable.tsx`
